# 🛒 Almacén — Proyecto #01

Proyecto web de un almacén de barrio moderno, desarrollado como parte del
portafolio de **ING.Marcsene**.

## 🎯 Objetivo

Crear una experiencia de compra sencilla, moderna y responsive para
visualizar productos, buscar artículos y gestionar un carrito de compras.

## ✨ Funcionalidades

- 🛒 Carrito de compras
- ➕➖ Control de cantidades
- 🔎 Búsqueda de productos
- 📂 Filtrado por categorías
- 💾 Persistencia del carrito con LocalStorage
- 💰 Cálculo automático del total
- 💱 Selector de moneda
- 📲 Generación de pedido mediante WhatsApp
- 📱 Diseño responsive
- 🖼️ Imágenes de productos

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
